# House finding app:

## Features:
- Be able to see comments and ratings on residences.
- Be able to find sublets and post sublet listings when on internship or summer.
- Scroll through listings & find other interested roommates
  - Can match with them 
  - Look at features of each listing
  - Examples: close to campus, Western verified, proximity to superstore 

## Stack:
Frontend: React
Backend: Express js

## Function Splitting:
 - Omar
   - Auth
   - Sublet




User Stories (western students only):
Student looking for good apartments/listings
As a western student
I want to be able to find comments and reviews on landlord/listing
So that I can find and know beforehand whether a listing sucks or not.

Student posting sublet
As a student having a gap semester or an internship
I want to be able to post my room/apartment for subletting
So that i dont have to pay rent fully even though i dont live there.

Landlord posting listing.
Landlord posts listing for students, we can verify if it's checked by western if it's scraped from the western page.
